# Cain Archive 0.2.1

*Stay awhile and download…*

A small fix release.

## Fixed

- **Source headings while scrolling.** When a search spans several sources, the heading of the group you're scrolling through now stays flush with the top of the list, instead of leaving a gap where rows showed through or covering the group's first row.

## Install

**Windows**

- **`Cain-Archive_0.2.1_x64-setup.exe`** (recommended): installs the app with a Start menu shortcut and an uninstaller, and sets up WebView2 if it's missing.
- **`Cain-Archive_0.2.1_x64-portable.zip`**: unzip anywhere and run `Cain Archive.exe`. Nothing is installed, but WebView2 must already be present (it comes with Windows 11).

The Windows files are not code-signed, so SmartScreen may warn you: choose *More info → Run anyway*.

**Linux** (x86-64)

- **`Cain-Archive_0.2.1_amd64.deb`**: for Debian, Ubuntu 22.04+ and derivatives. Install with `sudo apt install ./Cain-Archive_0.2.1_amd64.deb`.
- **`Cain-Archive_0.2.1_amd64.AppImage`**: runs on most distributions without installing. Make it executable (`chmod +x`) and start it.

`SHA256SUMS.txt` lists the checksum of every file.
