# Cain Archive 0.1.0

*Stay awhile and download…*

The first public release of Cain Archive, an unofficial desktop downloader for the [Internet Archive](https://archive.org).

## Highlights

- **Collections and subcollections.** Save the archive.org items you use into named collections (one level of nesting). File lists are kept locally, so search is instant.
- **Combined search.** Search file names across a collection, a single source or all of them. Filter by extension, sort by name or size, and see at a glance what's already downloaded or queued. Your selection is kept between searches.
- **Reliable downloads.** Up to 8 at once, resumed via HTTP Range after interruptions, retried automatically, and kept in a queue that survives closing the app. Reorder the queue by dragging.
- **Import / export.** Move collections in and out as plain text or CSV, or drop a list file onto the window.
- **Login** for items that need an archive.org account. Your password is never stored.
- **English or Italian, light or dark.** Both follow the system by default, and new languages can be added with a single translation file.

## Install

**Windows**

- **`Cain-Archive_0.1.0_x64-setup.exe`** (recommended): installs the app with a Start menu shortcut and an uninstaller, and sets up WebView2 if it's missing.
- **`Cain-Archive_0.1.0_x64-portable.zip`**: unzip anywhere and run `Cain Archive.exe`. Nothing is installed, but WebView2 must already be present (it comes with Windows 11).

The Windows files are not code-signed, so SmartScreen may warn you: choose *More info → Run anyway*.

**Linux** (x86-64)

- **`Cain-Archive_0.1.0_amd64.deb`**: for Debian, Ubuntu 22.04+ and derivatives. Install with `sudo apt install ./Cain-Archive_0.1.0_amd64.deb`.
- **`Cain-Archive_0.1.0_amd64.AppImage`**: runs on most distributions without installing. Make it executable (`chmod +x`) and start it.

`SHA256SUMS.txt` lists the checksum of every file.
