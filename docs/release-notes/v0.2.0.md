# Cain Archive 0.2.0

*Stay awhile and download…*

A smaller release focused on handling collections and the queue more smoothly.

## Highlights

- **Drag from anywhere.** Grab a collection or a queued file anywhere on its row to reorder it. The row follows the pointer and the others slide out of the way.
- **Export several collections at once.** Ctrl+click or Shift+click to select them, then *Export N collections*: each one is saved as its own list file in the folder you pick.
- **Enable or disable all sources** of a collection (and its subcollections) from its menu.
- **Results grouped by source.** When a search spans several sources, each gets its own heading.
- **Proper menus and confirmations.** Right-click a collection to open its menu, and deleting one now asks in a dialog.

## Install

**Windows**

- **`Cain-Archive_0.2.0_x64-setup.exe`** (recommended): installs the app with a Start menu shortcut and an uninstaller, and sets up WebView2 if it's missing.
- **`Cain-Archive_0.2.0_x64-portable.zip`**: unzip anywhere and run `Cain Archive.exe`. Nothing is installed, but WebView2 must already be present (it comes with Windows 11).

The Windows files are not code-signed, so SmartScreen may warn you: choose *More info → Run anyway*.

**Linux** (x86-64)

- **`Cain-Archive_0.2.0_amd64.deb`**: for Debian, Ubuntu 22.04+ and derivatives. Install with `sudo apt install ./Cain-Archive_0.2.0_amd64.deb`.
- **`Cain-Archive_0.2.0_amd64.AppImage`**: runs on most distributions without installing. Make it executable (`chmod +x`) and start it.

`SHA256SUMS.txt` lists the checksum of every file.
